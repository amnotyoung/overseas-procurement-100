한 장 캔버스

수원부처와 개발파트너가 국가·부문 우선순위에 맞는 사업을 발굴하고, MIFER 산하 FERD 단일창구를 통해 정부 고위 승인, 양자 협정·MoU·교환각서 협상과 서명, AIMS 등록, 이행 모니터링으로 연결한다.

절차

  1. 수원부처·정부기관 또는 개발파트너가 사회경제 개발 수요와 지원 가능성을 협의
  2. 단일 또는 복수 수원기관 중 선도 정부기관을 정하고 국가·부문·지역 계획과 중복 여부를 검토
  3. 사업개념서와 관련 문서를 FERD 단일창구에 제출 — 주/지역 정부 제안은 해당 최고책임자 사전승인 확인
  4. FERD가 DACU 검토와 필요한 고위 승인 절차를 조정하고, 승인된 제안을 개발파트너에 공식 전달
  5. 개발파트너가 자체 심사·승인을 진행하고 수원기관과 전체 사업설계·예산·조달계획을 구체화
  6. FERD가 양자협정·MoU·Exchange of Notes 초안에 관계부처 법률의견을 취합하고 개발파트너와 협상
  7. 최종안을 경제·정부 고위 승인회의에 상정 — 현행 승인기관 명칭과 권한은 서명 전 재확인
  8. 권한 있는 당사자가 협정·MoU·교환각서를 서명하고 FERD·AIMS에 사업정보와 문서를 등록
  9. 수원부처와 개발파트너가 PMU·PSC로 사업을 이행하고 FERD가 분기보고·제약사항·중복을 모니터링

적용 대상

미얀마 정부기관과 공식 협정·MoU·교환각서 등으로 연결되는 양자·다자 무상, 양허성 차관, 기술협력 사업에 적용한다. 개발파트너가 미얀마 정부기관과 공식 협정 없이 독립적으로 재원조달·집행하는 독립사업은 2020 DAP 승인절차의 적용 제외다. 2020 DAP는 MIFER를 DACU 심의의 단일창구로 정하고 사업개념 승인→최종 설계 승인→협정 서명→FERD 보고를 규정했으나, 2021년 이후 정부구조 변화로 경제위원회·DACU·최종 승인기관의 정확한 현행 권한은 서명 전에 확인해야 한다.

유의사항 · 병목

  • 2020 DAP는 국가고문·의회·경제위원회를 전제로 작성됐고 2021년 이후 정부구조가 바뀌었다. 현재 MIFER 페이지도 국정관리평의회 회의를 적고 있어 2026년 현재 최종 승인기관 명칭·권한을 그대로 적용할 수 없다
  • 사업개념 승인과 최종 설계 승인을 FERD 단일창구·DACU 검토로 두 단계 진행해 문서 품질·번역·관계기관 의견 취합이 일정에 직접 영향을 준다
  • 개발파트너 자체 승인과 미얀마 정부 승인이 병렬로 필요하며, 협정안 법률의견·고위 승인이 끝나기 전에는 공식화할 수 없다
  • 외부재원 조달은 개발파트너 규정이 우선할 수 있어 사업형성 단계에서 재원협정의 조달 우선순위를 확정해야 한다
  • MIFER 공식 기능 페이지와 2020 DAP는 AIMS 등록·분기보고·PMU/PSC 모니터링을 요구하나 공개 시스템의 현재 운영상태는 확인하지 못했다

진입장벽

  • FERD 단일창구와 수원부처를 모두 거쳐야 하므로 초기에 선도 정부기관과 공식 연락경로를 확정해야 한다
  • 영문 문서 품질과 미얀마어 번역 정확성이 승인 지연 요인으로 DAP에 명시돼 있다
  • 현행 고위 승인기관과 서명권자를 협정 협상 초기에 서면 확인하지 않으면 최종 단계에서 재상신될 수 있다

Once a project/programme concept has been agreed, the Government Entity shall submit all relevant documentation to FERD who shall prepare the case for submission to the DACU.
